THE MEASURED CHILD 2055

Open index.html in a modern browser.

Files:
- index.html: complete website structure and English narrative text
- styles.css: responsive visual design
- script.js: interactions, choices, privacy mode, endings and countdown
- assets/learnscore_promo.mp4: original animated promotional video
- assets/ambient.wav: original ambient audio loop
- assets/poster.png: video poster

Main interactive elements:
1. Identity-card login reveal
2. Learning-credit category explorer
3. Student-score explorer
4. Wellbeing choice
5. Focus test
6. After-school choice
7. Private-message tabs
8. Three different endings
9. Privacy mode
10. Audio control

The site is designed to run locally without an internet connection.
