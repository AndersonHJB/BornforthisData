#2 Javascript Fundamentals

- Today we will be having our first go at Javascript - if you can master these functions and implement them yourself you will have the elementary skills needed for your assignments. We will go into more detail next week - so don't panic if it feels a bit too in-depth.

The simplest way to understand Javascript is as a means of changing elements and CSS properties in your page following an 'event' - most commonly when a user clicks, but there are others - see link. You can change the attributes, parameters and variables of any HTML element or CSS property. You can also create and remove elements. Javascript is the primary method for making our pages dynamic and interactive!

- Click on the heading above and see what happens. When we click the 'h1' element, we run the function 'changeHeading' to replace the original text with new text. Most of the functions you will use in your site will work in this way. Let's have a look at our code and get a sense of how #id, 'onclick' and the function are all linked - you will need to remember this hierarchy to implement your own functions. This is the MOST important part of this lesson - understand how these pieces of code are linked.

- This terminology isn't super important right away but it helps to understand how functions work:

1. 'document' - this tells the browser we're going to retrieve something from within our code.

2. 'getElementById' - This is the most common 'method' for retrieving an element.

3. 'innerHTML' - this part of the function directs Javascript to the HTML page. We could also use 'style.property = value;' if we want to change a CSS property. ** Click this list item to see an example of a function that changes the 'background' property of this .container div and another below.
