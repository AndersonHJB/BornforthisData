The HTML DOM

The HTML DOM (Document Object Model) is a model of a web document that is created by a web browser when a page is loaded - it takes the form of a tree of objects, as you can see in the image here.

JavaScript is used to manipulate the DOM, allowing the dynamic manipulation of web pages.

For example:

JavaScript can change all the HTML elements in the page

JavaScript can change all the HTML attributes in the page

JavaScript can change all the CSS styles in the page

JavaScript can remove existing HTML elements and attributes

JavaScript can add new HTML elements and attributes

JavaScript can react to all existing HTML events in the page

JavaScript can create new HTML events in the page

Key Terms for Programming

JavaScript is an object oriented scripting language and as such employs a number of the below standard programming features.

Functions

Functions execute specific actions – some accept parameters, others don’t.

Parameters

Comma separated elements between parentheses are called parameters and they affect how a function works.

Statements

The coding equivalent of a sentence – a complete unit of code terminated with a semicolon.

Block

A section of code that is run together – delimited using curly brackets.

Variables

Variables are used to store and retrieve values.

Methods

Methods are things objects can do – they are used by typing them following an object name with a dot in between.

JavaScript Statements

JavaScript statements can include values, operators, expressions, keywords and comments, and they always end with a semi-colon.

It is common for statements used on standard web documents to look something like this:

document.getElementById("statement").innerHTML = "Hello World";

The above example is using the 'document.getElementById' method to access the DOM and find an element in the web document with the id 'statement', before using the '.innerHTML' method to change the text in that element.

JavaScript Functions

Along with adding JavaScript directly to an HTML event attribute it is also possible to use an event to 'call' - load and run - a JavaScript function.

JavaScript functions are blocks of code that 'do' something - once defined functions can be called as often as you like.

Functions are defined using the 'function' keyword followed by a unique name of your choosing for the function and a set of brackets and then curly brackets containing the code to be executed in the function.

Task - Now try out using functions in your project.

Function parameters are listed inside the brackets next to the name you give a function - functions often don't have any parameters, such as in the cases above, but if they do those parameters set what arguments the function can receive in the form of values, which are then stored as local variables.

Functions can also include a return statement - in such cases the function will stop when it reaches the return statement and 'return' a 'return statement' to the 'caller'

For example, this function that calculates the result of adding three numbers using the expression a+b+c:

        function myCalculator(a, b, c) {
                        return a + b + c;
                    }

Functions like the one above that return a result can be called by declaring a variable, which stores the results and can be used to represent it using a name of your choice.

For the above that looks like this:

        
        var result = myCalculator(3, 2, 1);

JavaScript is very flexible and will let you store most data types as variables using 'var' - numbers and more.

Remember the operator () invokes a function and the word 'function' defines one - refer back to the examples above.
