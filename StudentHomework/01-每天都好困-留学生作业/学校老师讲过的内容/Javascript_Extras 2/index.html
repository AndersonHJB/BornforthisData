Random Image From Array




Click Link

This function returns random images from an array, and changes the href attribute of the link that appears below it. See if you can figure out how it works. HINT: If you comment out one of the statements in the function, the link text will remain unaffected, although the url target will still update.

This example, like most of the examples today, uses an array - which is a type of variable that allows you to keep items in a list.

You may notice the word 'push' in the array list in our Javascript file. This one of a number of array methods that allow you to do various things with the items in an array. See here for a list.

Random Word Generator

This function creates a new paragraph element for each new word. See a more thorough explanation here.

The function 'randomWord' produces a random value and uses it to return a random word from our array. It then generates a text node and a paragraph element to hold each word, and appends the new element to a parent div. See here. This function also applies a class to all the generated 'p' tags and applies a randomly generated number to the transform property of that class.

A second function applies an id to first five of these new elements, enabling us to style them seperately. See if you can figure this out and possibly create a more elegant solution.
